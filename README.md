# Supply Shortage Planning — Learning Starter

**Status: partial starter, not a complete challenge submission.** Python 3.10+; no third-party dependencies.

## Run on Windows (PowerShell)
```powershell
py -3 -m src.main --out outputs/sample
py -3 -m unittest discover -s tests -v
py -3 -m src.main --skus 3000 --locations 50 --weeks 52 --suppliers 500 --orders 10000 --out outputs/full
```

## Current behavior
Deterministically generates SKU, location, supplier, capacity, lead-time, weekly forecast, inventory and purchase-order CSVs. Projects week-by-week balances, records shortages and unverified mitigation *candidates*, and writes a manifest and separate illustrative ground-truth cases.

## IMPORTANT: Not implemented yet
Supplier-specific SKU eligibility and capacity-aware mitigations; real BOM and production planning; effective-date and lifecycle enforcement; event sourcing; genuine injected anomalies with affected record IDs; comprehensive PK/FK, UOM, lifecycle and duplicate validation; JSON/SQL exports; complete data dictionary; source manifest; full evaluation metrics. The current mitigation options are **not** policy-approved or executable. The ground-truth cases are placeholders and not injected anomalies. Do not claim full acceptance compliance.

## Reproducibility
Run identical commands with `--out outputs/run1` and `--out outputs/run2` and compare `manifest.json` SHA256 dictionaries.
